Rclone-Proxmox

Informativa privacy

Aggiornata il 26 ottobre 2026.

Gestore e finalità

Rclone-Proxmox è una configurazione privata di Rclone gestita dal titolare dell'account GitHub Isakkino. Serve esclusivamente al proprietario dell'account Google autorizzato per sincronizzare i propri file sul proprio server.

Dati trattati

Il programma accede a contenuti e metadati dei file Google Drive, come nomi, percorsi, identificativi, dimensioni e date, per confrontare e sincronizzare le cartelle selezionate e gestire versioni precedenti e conflitti. I dati non sono utilizzati per pubblicità, profilazione o addestramento di modelli AI.

Conservazione

Token e credenziali OAuth sono conservati nella configurazione del server personale e possono essere trattati sul computer usato per autorizzarlo. File, registri e indici restano nell'infrastruttura del proprietario. I registri possono contenere nomi e percorsi. Copie e versioni sono conservate finché il proprietario non le elimina o applica una politica di conservazione.

Trasferimenti

I dati sono scambiati con Google Drive per la sincronizzazione richiesta. I file inclusi in un eventuale collegamento configurato dal proprietario con Dropbox possono essere trasferiti anche a Dropbox. Questo sito non riceve file o credenziali della sincronizzazione. I dati non vengono venduti.

Revoca e cancellazione

Il proprietario può fermare il programma e revocare l'accesso dalle connessioni di terze parti del proprio account Google. La revoca non elimina le copie già conservate sul server o su altri servizi, che vanno cancellate separatamente.

Hosting e contatti

Questo sito non include analytics, pubblicità o script di tracciamento propri. GitHub Pages può trattare dati tecnici delle visite secondo la privacy policy di GitHub.

Contatti: profilo GitHub del gestore. Non inviare dati personali o credenziali tramite issue pubbliche.
