Rclone-Proxmox

Configurazione privata di Rclone, gestita dal titolare dell'account GitHub Isakkino per sincronizzare i propri file Google Drive con il proprio server personale.

Destinata esclusivamente all'uso personale del proprietario dell'account Google autorizzato. Non offre registrazioni pubbliche e non è un prodotto Google né il sito ufficiale di Rclone.

Funzionamento

Il programma può elencare e leggere i file e, se configurato per la sincronizzazione bidirezionale, crearli, aggiornarli, spostarli o eliminarli. Le cartelle sono selezionate nella configurazione locale; il permesso OAuth può dare accesso a un insieme più ampio di file.

Questo sito è soltanto informativo: non riceve i file sincronizzati né credenziali OAuth.
